# Data Exploration and Visualisation (Python)

Practical assignments from my B.Sc. (Physical Science with Computer Science) course at Keshav Mahavidyalaya, University of Delhi. They cover data handling, cleaning, exploration and visualisation in Python.

## Notebooks
| Notebook | Topic | Libraries |
|---|---|---|
| practial(1) (2).ipynb | NumPy arrays (arange, reshape) and statistics | NumPy, SciPy |
| practical2.ipynb | Penguins dataset: shape, data types, head/tail, iloc indexing, summary statistics | Pandas, Seaborn |
| practical3.ipynb | Titanic dataset: removing duplicates, filling missing ages with the median, filtering, groupby, new "Family Size" column | Pandas, NumPy, Seaborn |
| practical4.ipynb | Iris dataset: scatter plots and histograms | Matplotlib, Seaborn |
| practical5.ipynb | Interactive charts on the Iris dataset | Plotly Express |

## Skills demonstrated
Data cleaning · Handling missing values · Exploratory data analysis · Filtering and groupby · Data visualisation (static and interactive)

## How to run
    pip install pandas numpy scipy seaborn matplotlib plotly scikit-learn jupyter
    jupyter notebook

Note: practical3 reads `titanic.csv` from a local path. Download the Titanic dataset and change the path to where you saved it.
